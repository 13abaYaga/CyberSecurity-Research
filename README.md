## 🇬🇧 English Version

### 📌 Overview
Welcome to my central repository for practical research, technical whitepapers, and hands-on case studies in the field of **Cyber Security**. 

This project aims to bridge the gap between theoretical security concepts and real-world applications. Instead of just discussing concepts, this repository provides **code-level analysis**, **modern SOC automation scenarios**, and **in-depth investigations** of advanced persistent threats (APTs) and modern malware.

### 📂 Research Topics & Projects

| Topic | Directory | Description |
|---|---|---|
| 🚨 **SIEM & SOAR Automation** | [`/SIEM-SOAR-Automation`](./SIEM-SOAR-Automation) | Modern SOC architectures, log analysis, False Positive management, and playbook integration for automated threat response at machine speeds. |
| 🦠 **Ransomware Analysis** | [`/Ransomware-Analysis`](./Ransomware-Analysis) | Malware reverse engineering, process hollowing, hybrid encryption algorithms (AES/RSA), and defense strategies against next-gen ransomware. |

### 📖 Research Formats
For each topic, the research is meticulously structured into three distinct formats to cater to different audiences:

- 📄 **Whitepaper:** In-depth, academic-level technical analysis and theoretical background for security architects and engineers.
- 🛠️ **Case Study:** Practical, hands-on forensic analysis, real-world laboratory scenarios, and technical walkthroughs for analysts.
- ✍️ **Blog Post:** High-level summary and strategic insights designed for general technical readers and C-level executives.

### 🚀 Technologies & Tools Mentioned
* **Defense & SOC:** Wazuh SIEM, SOAR Playbooks, Firewalls, EDR, Network Segmentation
* **Reverse Engineering:** IDA Pro, x64dbg, Ghidra, Any.run Sandbox
* **Offensive Concepts:** EternalBlue (SMBv1), DGA, In-Memory Injection, Living off the Land (LotL)

### 📌 Proje Özeti
**Siber Güvenlik** alanındaki pratik araştırmalarımı, teknik makalelerimi (whitepaper) ve laboratuvar vaka çalışmalarımı paylaştığım merkezi depoya hoş geldiniz.
